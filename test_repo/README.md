# JWT Authentication Service

## Overview

This repository provides a **minimal, self‑contained example** of a JSON Web Token (JWT) based authentication system written in pure Python. It demonstrates the core concepts of:

- **Token creation** and **verification** using the `PyJWT` library.
- **User management** (registration and login) with an in‑memory store.
- **Authentication flow** that validates a JWT and extracts the user identifier.
- **Automated testing** with `pytest` covering all major behaviours.

The code is intentionally lightweight so it can be used as a teaching aid, a quick prototype, or a starting point for a more feature‑rich service.

## Usage Example

Below is a quick example of how the library can be used in a Python script:

```python
from app import register, login, authenticate
from auth import verify_token

# Register a new user
register('alice', 's3cr3t')

# Log the user in – this returns a JWT token
jwt_token = login('alice', 's3cr3t')
print('JWT:', jwt_token)

# Later, validate the token and retrieve the user id
user_id = authenticate(jwt_token)
print('Authenticated user:', user_id)

# Directly decode the token if you need the payload
payload = verify_token(jwt_token)
print('Token payload:', payload)
```

Running the snippet will output something similar to:

```
JWT: <encoded‑jwt>
Authenticated user: alice
Token payload: {'user_id': 'alice'}
```

## Security Considerations

- **Secret Management** – The secret key (`SECRET = "my-secret"`) is hard‑coded for demonstration only. In production, load it from a secure environment variable or secret manager.
- **Password Storage** – Passwords are stored in plain text within the `_USERS` dictionary. Real applications should hash passwords using a strong algorithm such as `bcrypt` or `argon2`.
- **Token Expiration** – Tokens generated here never expire. Add an `exp` claim when encoding to enforce token lifetimes.
- **HTTPS** – Always transmit tokens over TLS to protect them from eavesdropping.
